# Verified Scores

Use the following evidence hierarchy:

1. Official 5000-segment `report.html` — submission/leaderboard claim.
2. Stock TinyPhysics `stock_cost` with parity record — verified checkpoint.
3. Batched optimizer cost — accepted only when parity is checked.
4. Screenshots, prose, and estimates — context, never score evidence.

Every reported number must state its scope. A score for `00000` is a
single-segment checkpoint. A ten-segment mean is a pilot. Neither may be called
the comma score.
